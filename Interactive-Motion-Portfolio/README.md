GSAP React Portfolio 🚀

A modern, high-contrast, interactive developer portfolio built with React, GSAP (ScrollTrigger), Tailwind CSS, and custom SVG icons. Designed specifically for showcasing frontend development projects, technical skills, and an interactive command-line interface.

✨ Key Features

Fluid GSAP Motion: Smooth entrance timelines, bento card stagger reveals, and scroll-triggered animations via ScrollTrigger.

Dynamic Project Filtering: Filter projects instantly by category (React & Motion, Web Apps, APIs & Data).

Inspect Modals: Detailed project popups highlighting key technical achievements and direct live/source links.

Responsive & Accessible: Clean typography, high-contrast light/dark balanced styling, and fully responsive layout for mobile, tablet, and desktop viewports.

🛠️ Tech Stack

Framework: React.js (Functional components & Hooks)

Styling: Tailwind CSS (Utility-first design tokens)

Animation: GSAP & ScrollTrigger plugin

Icons: Custom lightweight SVG wrapper components

🚀 Getting Started

Prerequisites

Make sure you have Node.js (v16 or higher) installed on your machine.

Installation & Setup

Clone the repository:

git clone https://github.com/your-username/gsap-react-portfolio.git
cd gsap-react-portfolio

Install dependencies:

npm install

Run the development server:

npm run dev
